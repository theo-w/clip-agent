## 版本 A：简历站「独立产品实践」板块（推荐，3 条）

1. **独立设计并交付「剪辑辅助 Agent」**：面向剪映 PC 创作者的 AI 辅助工具，将静音裁切、字幕校对、高光筛选等 5 项高频重复操作封装为**可插拔 Agent Skill**，自然语言一句话完成批量处理；设计「意图解析 → Skill 调度 → 预览快照 → 采纳/修改/放弃」四段式工作流，**AI 结果先预览、用户确认才应用，原素材零风险**。
2. **建立创作资产库与评测体系**：调色预设/字幕模板/组合方案支持检索、收藏与**版本回滚**；埋点采纳率、二次修改率、报错率三类指标，**口径设计沿用客服"解决率"防虚高经验**（用户确认应用才计采纳）。
3. **完成可运行验证**：40 项自动化测试全绿，4 条端到端链路实测（静音裁切成片、字幕四类问题自动修正、BGM 6s 精确对齐、调色前后对比）；规则路由兜底 + 本地大模型增强，**无网络依赖可离线演示**。

## 版本 B：BOSS 直聊 / 自我介紹一句话版

> 我做了个「剪辑辅助 Agent」作品集：把智能客服里验证过的「AI 承担重复劳动、人保留判断权」方法论迁移到剪映场景——5 个可插拔 Agent Skill、预览确认制、资产库与采纳率评测，能现场演示。附 SDD 与复盘文档。
