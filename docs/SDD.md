# 剪辑辅助 Agent · SDD 文档

> 产品 SDD，可交付开发，面试可展示
>
> - **项目名称**：剪辑辅助 Agent（剪映 PC 生态辅助 Agent）
> - **版本**：V1.0
> - **定位**：面向短视频创作者，基于多模态大模型 + 工具调用，封装剪辑 Skill，自动化标准化剪辑任务，沉淀创作预设资产库
> - **用途**：面试展示、给开发看、放到 GitHub README 引用
> - **说明**：SDD 兼顾【产品需求 + 模块设计 + 边界约束 + 指标】，不是纯 PRD，偏向设计规格文档

## 1. 项目概述

### 1.1 项目目标

面向剪映 PC 专业版创作者，解决剪辑链路中大量重复、低创意的标准化操作；通过 Agent + 可复用 Skill 单元，接收自然语言指令，自动串联剪辑工具动作；配套创作资产库，沉淀调色、字幕、参数预设，提升创作者剪辑效率。

**核心定位：AI 是创作者的助手，不是全自动剪辑替代；保留人工编辑控制权。**

### 1.2 业务背景

创作者剪辑链路：导入素材 → 粗剪 → 字幕处理 → 音频处理 → 调色 → 特效 → 导出。

痛点：

1. 大量规则明确、重复执行的操作消耗时间；
2. 剪映现有 AI 能力多为单点能力，缺少可编排、可复用、可串联的自动化技能；
3. 创作者优质参数预设难以沉淀、复用、分发。

### 1.3 范围

✅ **包含**：自然语言指令解析、Skill 管理调度、多模态素材识别、创作资产库、效果评测、结果预览、人工干预入口

❌ **不包含**：剪映底层内核开发、复杂创意叙事生成、强主观艺术自动剪辑

### 1.4 用户角色

| 角色 | 说明 |
|---|---|
| 核心用户 | 短视频剪辑师、自媒体创作者（剪映 PC 专业版用户） |
| 管理员 | 资产维护者（整理优质 Skill、预设模板） |

## 2. 需求清单

### 2.1 核心能力需求

1. **指令理解**：接收自然语言，识别用户意图，匹配可用 Skill；支持单 Skill 执行、多 Skill 串行编排。
   示例指令：`识别视频静音片段并自动裁剪`、`批量校对所有字幕错别字，统一字体样式`、`筛选高光镜头，匹配BGM卡点`
2. **Skill 单元管理**：Skill 独立封装、参数可配置、开关可控；支持新增 / 编辑 / 上下线 Skill。
3. **素材识别能力**：读取视频帧、音频轨道、字幕文本，识别静音、口播文本、镜头变化。
4. **创作资产库**：存储调色预设、字幕模板、参数配置包；支持保存、检索、收藏、一键加载、版本管理。
5. **结果交互**：AI 执行完成后，生成预览，创作者可单步撤销、修改参数、手动调整，再确认应用到剪辑工程。
6. **评测与数据埋点**：自动记录 Skill 调用链路、耗时、采纳 / 修改 / 放弃行为，输出效果报表。

### 2.2 非功能性需求

1. **本地部署优先**：支持 MLX/Ollama 本地模型运行，降低云端依赖、素材隐私风险。
2. **容错能力**：Skill 执行失败时，给出失败原因，支持用户调整参数重试，不破坏原有剪辑工程。
3. **可扩展**：后续新增 Skill（批量转码、字幕翻译、镜头防抖预处理）不需要改动 Agent 调度核心。
4. **性能**：单 Skill 执行响应可控，长视频任务支持进度展示。

## 3. 系统模块设计

### 3.1 模块总览

1. 意图解析 & 路由模块（大模型层）
2. Skill 调度引擎（核心编排层）
3. 素材识别模块（多模态分析）
4. 创作资产库模块
5. 结果预览 & 人工干预模块
6. 数据采集 & 评测模块
7. Skill 仓库（可插拔技能集合）

### 3.2 各模块详细设计

#### 模块 1：意图解析 & 路由模块

- **输入**：用户自然语言指令 + 当前素材上下文
- **输出**：识别意图、选择 Skill、提取参数、生成执行计划
- **逻辑**：
  - 先做意图分类，匹配注册在仓库里的 Skill；
  - 提取参数：视频范围、字幕样式、阈值、规则；
  - 输出 DAG 执行计划：串行 / 并行执行顺序；
  - 边界判断：无法识别、主观创意类指令 → 返回提示，拒绝全自动执行。

#### 模块 2：Skill 调度引擎（核心）

对应 JD 里的 Agent Skill，是整个项目的核心。

- **Skill 定义标准**：每个 Skill 是独立原子任务，有【入参、前置依赖、执行动作、输出、失败判定规则】。
- **内置 Skill 清单（V1.0）**：

| ID | Skill | 说明 |
|---|---|---|
| S1 | 静音片段自动裁切 | 识别音频低于阈值的静音段，生成裁剪时间戳 |
| S2 | 字幕批量校对、样式统一 | 规则修正标点/折行/重叠/重复，统一样式参数 |
| S3 | 高光镜头识别筛选 | 基于切变与响度的启发式评分（V1.1 接入多模态精排） |
| S4 | 音频 BGM 时长对齐 | BGM 与目标时长对齐：裁剪或循环，尾部淡出 |
| S5 | 批量调色参数套用 | 从资产库读取预设，生成滤镜链与剪映参数映射 |
| S6 | 语音转写生成字幕（V1.1，可选依赖） | 本地 Whisper 后端（mlx-whisper / faster-whisper）把音视频转写为 SRT，作为 S2 的上游输入；未安装后端时明确提示，不影响核心链路 |

- **调度规则**：支持顺序执行；每一步执行完成后，产出中间结果，用户可以随时介入打断。
- **失败策略**：单 Skill 失败，终止后续流程，返回错误信息，保留前面已经完成的结果。

#### 模块 3：素材识别模块

- **能力**：音频静音检测、字幕 OCR / 文本解析、镜头切变检测、画面内容识别。
- **依赖**：多模态模型、音视频基础处理工具。
- **输出**：结构化标签、时间戳片段，供给 Skill 使用。

#### 模块 4：创作资产库

- **数据结构**：资产 ID、资产类型（调色 / 字幕模板 / Skill 组合方案）、参数 JSON、标签、创建时间、版本、收藏数；V1.1 扩展：分享码、使用许可、Skill 依赖声明（`[{"skill_id", "min_version"}]`）、导入计数。
- **能力**：检索、标签筛选、另存为、版本回滚；V1.1 流通：导出 `.clipasset` 分享文件、分享码（内容哈希生成）、导入即用（依赖校验：Skill 未注册/停用/版本不满足 → 明确报错；同码同参数幂等，同码新参数升级为本地新版本）；V1.1 组合模板：`skill_combo` 类型资产定义 steps 序列，CLI `--combo` 一键执行整条流水线；P2 本地发现：`assets discover` 聚合本地埋点计算质量分（50%×去重素材复用 + 30%×收藏 + 20%×导入），复用按独立素材去重（防刷），输出质量分排行与 `output/square.html` 资产广场页。
- **权限**：个人资产（私有）、公共优质资产（推荐）。
- **安全边界**：资产是参数不是代码——`.clipasset` 只含参数与元数据，不含可执行内容。

#### 模块 5：预览 & 人工干预模块

- 所有 AI 输出不直接覆盖原工程，先生成预览快照；
- 预览双形态：`report.md`（机器读/可版本控制）+ `report.html`（可视化、单文件可分享，产物链接与调色对比图 base64 内嵌）；`report --html` 生成评测仪表盘 `output/report.html`，`assets discover --html` 生成资产广场 `output/square.html`（同一套自包含样式与转义规则）；
- 操作：单步撤销、修改参数、手动编辑片段、确认应用、直接放弃本次 AI 结果；
- **设计原则**：人机边界清晰，创作者拥有最终控制权。

#### 模块 6：数据 & 评测模块

采集埋点：Skill 调用次数、调用耗时、是否采纳、二次修改时长、放弃原因、报错类型。

输出指标报表：

1. **效率指标**：任务平均耗时下降、操作步骤减少量；
2. **质量指标**：结果采纳率、二次修改率、报错失败率；
3. **生态指标**：资产保存率、复用率、分享率。

## 4. 核心流程：用户一次完整调用流程

1. 用户上传 / 绑定剪映工程素材，输入自然语言指令；
2. 意图模块解析指令，匹配 Skill，生成执行计划；
3. 调度引擎依次调用 Skill，调用素材识别模块拿到时间戳、标签等数据；
4. 执行剪辑动作，生成预览结果，不修改原工程；
5. 用户查看预览：选择【直接应用】/【修改参数重跑】/【放弃】；
6. 行为数据上报评测模块，资产可选择保存到资产库。

## 5. 数据结构（简化，给开发参考）

```json
// Skill 元数据示例
{
  "skill_id": "S001",
  "name": "静音片段裁切",
  "desc": "识别音频低于阈值的静音段，生成裁剪时间戳",
  "params": {"silence_threshold": -30, "min_duration": 0.5},
  "input": ["audio_track", "video_timeline"],
  "output": ["cut_time_list"],
  "is_enable": true
}
```

## 6. 约束与边界（面试高频，非常重要）

1. 主观创意类需求（镜头叙事、创意转场、情绪剪辑）不做全自动 Skill，只做辅助推荐；
2. AI 结果必须预览确认，禁止静默覆盖用户原始剪辑工程；
3. Skill 设计遵循：规则明确、可验证、出错修改成本低；
4. 模型能力有上限，在指令入口做好预期管理，不承诺 100% 完美结果。

## 7. 版本迭代规划

- **V1.0**：5 个基础 Skill、本地调度、个人资产库、基础评测；
- **V1.1（已完成）**：资产流通已实现——导出 `.clipasset` / 分享码 / 导入即用（含依赖校验与幂等判重）+ Skill 组合模板（资产驱动执行计划，CLI `--combo` 一键执行）+ S006 语音转写（可选依赖）+ HTML 预览报告与评测仪表盘 + 本地资产广场（质量分聚合、独立素材去重、`assets discover`）；待做：在线资产广场（平台承载）、多模态高光精排；
- **V1.2**：对接剪映开放 API，直接和剪映工程联动（现在剪映 PC 开放能力有限，作为远期规划）。

## 8. 风险

- **音视频识别精度不足**：增加参数可调、人工标记 Bad Case 迭代；
- **指令歧义**：增加澄清追问，多候选方案给用户选择；
- **剪映 API 限制**：现阶段作为独立辅助工具，输出时间戳方案，手动导入剪映。
